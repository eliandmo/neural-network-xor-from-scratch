Abstract

This report documents the step-by-step training of a feedforward neural network applied to the XOR binary classification problem, following the class notes of Llinás (2026). Starting from parameters at the end of Epoch 2, the third epoch is computed manually and verified numerically, yielding \(\hat{y} = 0.57924\) and \(E = 0.08852\). Automated training over 15 epochs confirms monotone loss reduction from \(0.09095\) to \(0.07520\) under learning rate \(\alpha = 0.25\). Experiments with an alternative initialization and a two-observation vectorized extension demonstrate that training data diversity is the primary driver of convergence speed. The full XOR dataset experiment (5,000 epochs, \(\alpha=1.0\)) converges to a local minimum with 50% accuracy, illustrating the non-convex nature of neural network optimization. All computations are performed from scratch using NumPy without any neural network library.

INTROIntroduction

The XOR (exclusive-OR) function is among the most instructive benchmarks in neural network theory. The XOR function maps two binary inputs to a binary output according to the rule: output is 1 if the inputs differ, and 0 otherwise:

\[ \text{XOR}(x_1, x_2) = \begin{cases} 0 & \text{if } x_1 = x_2 \\ 1 & \text{if } x_1 \neq x_2 \end{cases} \]

METHODMethodology

Network Architecture

The network reproduces Figure 12.1 of the class notes (Llinás, 2026): two input neurons → two hidden sigmoid neurons → one output sigmoid neuron, with bias nodes \(b_1, b_2\) (hidden) and \(b_3\) (output).

Forward pass:
\( z_j = \sum_i w_{ij}\,x_i + b_j \), \( h_j = \sigma(z_j) \)
\( z_3 = w_5 h_1 + w_6 h_2 + b_3 \), \( \hat{y} = \sigma(z_3) \)
Loss and update rule:
\( E = \dfrac{1}{2}(y - \hat{y})^2 \)
\( w_i \leftarrow w_i - \alpha\,\dfrac{\partial E}{\partial w_i} \), \( \alpha = 0.25 \)

Activation Function

The logistic sigmoid \(\sigma(z) = \dfrac{1}{1+e^{-z}}\) is used at every neuron. Its derivative \(\sigma'(z)=\sigma(z)(1-\sigma(z))\) appears in every backpropagation step.

Backpropagation Equations

\[ \frac{\partial E}{\partial z_3} = (\hat{y}-y)\,\hat{y}(1-\hat{y}) \] \[ \frac{\partial E}{\partial z_1} = \frac{\partial E}{\partial z_3}\cdot w_5\cdot h_1(1-h_1), \qquad \frac{\partial E}{\partial z_2} = \frac{\partial E}{\partial z_3}\cdot w_6\cdot h_2(1-h_2) \] \[ \frac{\partial E}{\partial w_k} = \frac{\partial E}{\partial z_j}\cdot x_k \qquad (\text{weight connecting input }k\text{ to layer }j) \]

§2 — Automated Training for 15 Epochs

Core training loop — from scratch, no ML libraries
for ep in range(1, 16):

§3 — Graphical Analysis of the Training Process

Reflection
Output-layer weights \(w_5, w_6\) update faster than hidden-layer weights \(w_3, w_4\) because their gradient path avoids the extra chain-rule multiplication through the hidden activation derivative \(h_j(1-h_j)\). This is the signature of the vanishing gradient through layers, visible even in this minimal two-layer architecture.

Why XOR requires a hidden layer. Without a hidden layer, \(\hat{y}=\sigma(w_1 x_1+w_2 x_2+b)\) — a single sigmoid on a linear combination. This produces only a linear decision boundary, insufficient to separate the diagonal XOR pattern \(\{(0,0),(1,1)\}\) vs \(\{(0,1),(1,0)\}\). The hidden layer generates nonlinear intermediate representations \(h_1, h_2\) whose combination creates the required curved boundary.

§7 — Conceptual Reflection: How the Network Learns from Mistakes

  • 1Prediction \(\hat{y}\). Forward propagation computes \(\hat{y}=0.57350\) at Epoch 1 — determined entirely by initial weights, not the target.
  • 2Error. \(y-\hat{y}=1-0.57350=0.42650\) — the "mistake" to be corrected.
  • 3Loss. \(E=\tfrac{1}{2}(y-\hat{y})^2\) is smooth, differentiable, and bounded below by zero. Its derivative \(\partial E/\partial\hat{y}=\hat{y}-y\) has the correct sign to push \(\hat{y}\) toward \(y\).
  • 4Gradient and backpropagation. The chain rule propagates \(\partial E/\partial z_3\) layer by layer, assigning proportional blame to each weight based on its contribution to the forward pass.
  • 5Update and improvement. \(w_i\leftarrow w_i-\alpha\cdot\partial E/\partial w_i\). After 15 epochs, \(\hat{y}\) increases from \(0.57350\) to \(0.61218\), \(E\) from \(0.09095\) to \(0.07520\).
The phrase “learning from mistakes” is mathematically precise: the loss encodes the mistake, the gradient distributes the blame proportionally, and the update applies a scaled correction. The improvement is incremental but guaranteed on smooth loss surfaces.

Critical Result — Local Minimum
The 50% accuracy outcome is not a code error. With np.random.seed(42), gradient descent converges to a configuration where the boundary approximates \(x_1=0.5\) rather than the true XOR regions. The near-zero gradient at convergence confirms a critical point, but it is a saddle or local minimum — not the global XOR solution. Practical remedies include multiple random restarts, momentum-based optimizers (Adam), or Xavier initialization.

DISCDiscussion

Gradient Information Requires Non-Zero Inputs

The chain rule gives \(\partial E/\partial w_1=(\partial E/\partial z_1)\cdot x_1\). When \(x_1=0\) identically, \(w_1\) and \(w_2\) are structurally frozen regardless of the loss magnitude or learning rate. This reveals a fundamental constraint: gradient descent can only learn what the data exposes. Two-observation training resolves this by providing \(x_1=1\) through the second observation.

Vanishing Gradient at Small Scale

Even in this minimal 2-2-1 network, \(|\partial E/\partial z_3|\) decreases monotonically across 15 epochs. The product \((\hat{y}-y)\cdot\hat{y}(1-\hat{y})\) shrinks as \(\hat{y}\to y\), and this effect compounds across layers. In deep networks, this becomes the exponential vanishing gradient that motivated ResNets, batch normalization, and ReLU activations.

Local Minima in Non-Convex Optimization

The full XOR experiment produces 50% accuracy after 5,000 epochs with a near-zero gradient at convergence. The network reached a stable configuration — a critical point — but not the global minimum. The closed-form analysis of the predictions shows the boundary is the union \(\{x_1=0.5\}\cup\{x_2=1\}\), a geometrically interpretable but incorrect separator for XOR. Gradient descent provides no global optimality guarantee on non-convex loss surfaces.

CONCConclusions

  • 1Manual verification confirmed. Epoch 3 yields \(\hat{y}=0.57924\), \(E=0.08852\), \(\Delta E\approx-0.00121\) — consistent with the class notes.
  • 2Structural gradient freezing. Training with \(x_1=0\) permanently freezes \(w_1, w_2\). Two-observation training resolves this and achieves \(\approx 2\times\) lower final loss.
  • 3Initialization matters. Non-zero biases provide \(3.3\times\) greater loss reduction in 15 epochs by activating additional gradient paths.
  • 4Local minima prevent global convergence. The full XOR experiment reaches a 50% accuracy local minimum, demonstrating that gradient descent provides no global optimality guarantee.
  • 5Hidden layer is necessary. No single sigmoid on a linear combination can produce the XOR boundary. At least one hidden layer is required to generate nonlinear intermediate representations.
Neural network training is governed simultaneously by mathematical guarantees (monotone loss reduction under appropriate \(\alpha\)) and practical limitations (local minima, frozen gradients, sigmoid saturation). Both dimensions are visible in this minimal XOR example, making it an exceptionally instructive benchmark.
